# Сайт для БДД №1 — Автотранс

Первый выбранный дизайн: синий, белый и оранжевый. Включены исправления мобильной вёрстки и копирования телефона.
Телефон: 8 (920) 518-56-56. География: Липецк, Липецкая область и другие регионы РФ.

## Загрузка на GitHub

1. Распакуйте ZIP на компьютере или телефоне.
2. Откройте нужный репозиторий GitHub.
3. Выберите Add file → Upload files (в пустом репозитории — uploading an existing file).
4. Загрузите распакованные файлы в корень репозитория. index.html должен лежать сразу в корне, рядом со styles.css, contact.js и изображениями.
5. Нажмите Commit changes. При обновлении замените одноимённые файлы.

Сам ZIP GitHub автоматически не распаковывает: загрузите его содержимое.
Документация: https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository

## Состав

- index.html — страница и тексты.
- styles.css — оформление и адаптация к телефону.
- contact.js — копирование номера.
- specialist.jpg — фото специалиста.
- truck.webp — изображение грузовика.

Сайт статический: установка npm, сервер приложения и сборка не нужны.
Для просмотра после распаковки откройте index.html в браузере.
Для размещения на обычном статическом хостинге загрузите пять файлов сайта в его публичную папку, сохранив имена.
Загрузка в репозиторий сама по себе не публикует сайт и не подключает домен. Настройка хостинга и домена выполняется отдельно.

## Проверка версии

В Chromium проверены ширины 320–1440 px, текст 200%, переходы к контактам, вопросы и копирование номера. На физических Android/iPhone эта версия не испытывалась.
Форм обратной связи и ссылок tel: нет. Кнопки переходят к контактам.
